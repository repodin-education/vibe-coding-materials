## 🎯 Mikä on Vibe Coding kurssi?

**Vibe Coding** on moderni koodauskurssi, joka opettaa käyttämään AI-työkaluja (Cursor) tehokkaasti oikeiden projektien rakentamiseen. Opit:

- ✅ **AI-avusteisen koodauksen workflow** – miten käytät Cursor AI:ta tehokkaasti
- ✅ **End-to-end web-kehitys** – server → browser -sovellusten rakentaminen
- ✅ **Modernit työkalut** – Git, GitHub, GitHub Classroom
- ✅ **Oppimistavoite** – rakennat oikean sovelluksen kurssin aikana

**Ei perinteistä koodausta:** Tämä kurssi ei opeta kirjoittamaan koodia käsin. Sen sijaan opit käyttämään AI-työkaluja niin, että saat aikaan hyvää, toimivaa koodia nopeasti.

---

## 💡 Miksi Vibe Coding?

### Ongelma: Perinteinen koodaus on hidasta - line by line, copy-paste chatGPT tai jotain muuta

- ⏱️ **Hidasta:** Kirjoitat koodia käsin, virheitä syntyy
- 🔄 **Toistuvaa:** Samat virheet uudestaan ja uudestaan
- 📚 **Teoreettista:** Opit syntaksia, mutta et käytännön työskentelyä (AI assisted)
- 🎯 **Epärealistista:** Todellinen työelämä käyttää AI-työkaluja (enemmän ja enemmän)

### Ratkaisu: Vibe Coding

- ⚡ **Nopeaa:** AI generoi koodin, sinä keskittyt logiikkaan
- 🎯 **Käytännöllistä:** Rakennat oikean sovelluksen
- 🚀 **Modernia:** Opit työskentelemään kuten ammattilaiset
- 💪 **Tehokasta:** Opit käyttämään AI-työkaluja oikein

## ❓ Usein Kysytyt Kysymykset

### Tarvitseeko maksaa Cursor AI:sta?

**Ei.** Cursor AI:n ilmainen versio riittää kurssin suorittamiseen täysin.

### Voiko käyttää muuta AI-työkalua kuin Cursor?

Kurssi on suunniteltu Cursorille, mutta voit käyttää muutakin AI-työkalua. Ohjeet ovat Cursorille optimoituja.

### Entä jos osaan vain Pythonia, en Node.js:ää?

**Ei hätää!** Kurssi käyttää Node.js:ää, mutta AI (Cursor) opettaa Node.js:n perusteet sinulle kurssin aikana. Keskity AI-työkalujen käyttöön - kieli tulee perässä. Node.js ja JavaScript ovat helposti opittavia, erityisesti AI:n avulla.

### Miten kurssi eroaa perinteisestä koodauskurssista?

- **Perinteinen:** Opit kirjoittamaan koodia käsin
- **Vibe Coding:** Opit käyttämään AI-työkaluja tehokkaasti

**Todellinen työelämä käyttää AI-työkaluja** – tämä kurssi opettaa sen.
