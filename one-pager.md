# Vibe Coding – Building with Cursor

> **"Opi käyttämään AI-työkaluja tehokkaasti koodaamiseen – rakentamalla oikeita projekteja"**

**Kurssin kesto:** 1–2 viikkoa osa-aikaisesti (6–10 tuntia) | **Taso:** Aloittelija → Pro-foundations | **Hinta:** Ilmainen

---

## 🎯 Mikä on Vibe Coding?

**Vibe Coding** on moderni koodauskurssi, joka opettaa käyttämään AI-työkaluja (Cursor) tehokkaasti oikeiden projektien rakentamiseen.

**Opit:**

- ✅ AI-avusteisen koodauksen workflow – miten käytät Cursor AI:ta tehokkaasti
- ✅ End-to-end web-kehitys – server → browser -sovellusten rakentaminen
- ✅ Modernit työkalut – Git, GitHub, GitHub Classroom
- ✅ Rakennat oikean sovelluksen kurssin aikana

**Ei perinteistä koodausta** – opit käyttämään AI-työkaluja niin, että saat aikaan laadukasta, toimivaa koodia nopeasti.

---

## 💡 Miksi Vibe Coding?

**Ongelma:** Perinteinen koodaus on hidasta – kirjoitat koodia käsin, virheitä syntyy, samat virheet toistuvat.

**Ratkaisu:** Vibe Coding – AI generoi koodin, sinä keskittyt logiikkaan. Opit työskentelemään kuten ammattilaiset.

---

## 📚 Mitä Opit?

**4 Moduulia, 3 Tehtävää:**

1. **Intro to Cursor + GitHub** (1h) – Ymmärrys AI-työkalujen käytöstä
2. **Vibe Coding Fundamentals** (2–3h) – Hyvien promptien kirjoittaminen, iteratiivinen kehitys
3. **E2E Hello World** (2–4h) – Toimiva web-sovellus (Node.js)
4. **Mini Feature** (1–2h) – Olemassa olevan sovelluksen laajentaminen

**Yhteensä:** 6–10 tuntia työtä, 3 tehtävää + pro-level -laajennukset

---

## 🎓 Kenelle Kurssi Sopii?

**✅ Sopii Sinulle Jos:**

- Olet ohjelmoinnin perusteet hallussa (muuttujat, funktiot, kontrollirakenteet)
- Tunnet jonkin ohjelmointikielen perusteet (JavaScript suositeltu)
- Haluat oppia käyttämään AI-työkaluja koodaamiseen
- Olet valmis rakentamaan oikean projektin kurssin aikana

**Tarvitset:**

- GitHub-tunnus (ilmainen: [github.com](https://github.com))
- Cursor AI (ilmainen versio riittää: [cursor.sh](https://cursor.sh))
- Node.js (v18+)
